Free Web Hosting & Official Deployment Guide

100% Free Forever Architecture: Because GridPulse is built as a single self-contained HTML/JS application connected to Firebase Cloud, you can host it publicly at $0/month with automatic HTTPS/SSL and global CDN speed.

1 Option A: Deploy on Firebase Hosting (Recommended)

  1. Create a free project at console.firebase.google.com and enable Authentication (Email/Password & Anonymous) and Cloud Firestore.
  2. Install Firebase CLI on your computer: npm install -g firebase-tools
  3. Place this index.html inside a public/ folder and run firebase init hosting followed by firebase deploy.
  4. Your site goes live immediately at https://your-project-id.web.app.

2 Option B: Instant Drag-and-Drop on Netlify Drop

Save this file as index.html inside a folder, visit app.netlify.com/drop, and drag the folder into your browser. You will get a live shareable HTTPS link in 10 seconds for free.

3 Option C: Free GitHub Pages Hosting

Create a free GitHub repository, upload index.html, go to Settings → Pages, and select the main branch to publish at https://username.github.io/gridpulse.
